# 🚀 System Dashboard & Project Management Hub

نظام متكامل لإدارة اللوحات، المتابعة التقنية، الكاميرات، وتوثيق المهام، مبني باستخدام إطار العمل **Flask** وقاعدة بيانات **SQLite** مع دعم للذكاء الاصطناعي والمراسلات التلقائية المجدولة[cite: 1, 2].

---

## ✨ المميزات الرئيسية

* **📊 إدارة الأقسام والمشاريع:** تتبع حالة المشاريع، المراحل الإنشائية، والروابط المرتبطة بدقة[cite: 1, 2].
* **📷 مراقبة الكاميرات:** لوحة تحكم متكاملة لإدارة وعرض كاميرات المراقبة مع حالة الاتصال والتوثيق بالصور[cite: 1, 2].
* **⏰ نظام التذكيرات التلقائية (Reminders):** مجدول خلفي (`BackgroundScheduler`) يفحص المهام دورياً ويرسل إشعارات عبر البريد الإلكتروني (SMTP) في المواعيد المحددة[cite: 1, 2].
* **🤖 مساعد الذكاء الاصطناعي المدمج:** محادثة ذكية متكاملة مرتبطة بقاعدة البيانات لتحليل حالة الكاميرات والمشاريع والإجابة عن الاستفسارات فورياً عبر نموذج Gemini[cite: 1, 2].
* **📁 إدارة المستندات والملفات:** رفع وترتيب المرفقات والتوثيقات الخاصة بكل قسم ومهمة بسهولة[cite: 1, 2].
* **⚙️ أقسام ونماذج مخصصة:** مرونة كاملة في إنشاء مجموعات ونماذج بيانات مخصصة بحسب الحاجة التقنية والتشغيلية[cite: 1, 2].

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Backend:** Python, Flask, Werkzeug, APScheduler
* **Database:** SQLite (مبني محلياً عبر `system_dashboard.db`)[cite: 1]
* **Email Service:** SMTP / Python `smtplib`[cite: 1]
* **AI Integration:** Google Generative AI API (Gemini)[cite: 1]
* **Frontend:** HTML, CSS, JavaScript, Jinja2 Templates[cite: 1]
